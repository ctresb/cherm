## Typing Indicator Suggestions

For a regular chat interface, avoid labels like `Thinking`, `Composing`, or `Generating`, since they can make the experience feel AI-oriented. Prefer subtle typing indicators that feel like a real conversation.

### Recommended Braille Typing Indicator

```txt
⠁
⠂
⠄
⡀
⢀
⠠
⠐
⠈
```

Example usage:

```txt
João is typing ⠁
João is typing ⠂
João is typing ⠄
João is typing ⡀
João is typing ⢀
João is typing ⠠
João is typing ⠐
João is typing ⠈
```

### Best Recommendation

For a modern terminal chat, use:

```txt
⠁ ⠂ ⠄ ⡀ ⢀ ⠠ ⠐ ⠈
```

This sequence is subtle, non-emoji, terminal-friendly, and feels more like an active typing state than a generic loading spinner.
