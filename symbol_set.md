## Safer Symbols for Terminal Compatibility

These are more likely to render consistently across terminals:

```txt
› ❯ → ← ✓ ✕ ○ ● ◉ ◆ ◇ ■ □ ▣ ▸ ▾ ─ │ ┌ ┐ └ ┘
```

## Avoid Emoji-Prone Symbols

These often render as colored emoji depending on the terminal, font, OS, or renderer:

```txt
⚙ 🔒 🔑 ✅ ❌ ⚠ 🚀 🛡 ⏳ ⌛
```
